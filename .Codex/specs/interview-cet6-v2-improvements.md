# 六级复习台 v0.3 改进需求（2026-10-17 访谈定稿）

## 核心目标
在不改变现有数据的前提下，提升日常使用体验：计时可跨页、数字口径统一、听力不再双声、
错题自动归档、题目完成度可见、写作可生成范文、词库可导出、考试/报名时间可配置。

## 关键决策（已确认）
1. **番茄钟**：作用域 A（/cet6 内跨页、刷新/关闭后按结束时间戳继续）；显示 A（右下角可隐藏胶囊）；
   结束 = 抖动 + 提示音（Web Audio 合成）→ 短暂番茄爆炸动画，不抢眼。
2. **复习数字口径**：方案 C —— 保持现状数字，统一文案：首页「共欠 422，今天先清 141」，
   词汇页「今天 141 / 剩余 281 分摊到之后 2 天」。每日发放量维持 3 天摊平。
3. **拼写回车**：回车 = 提交；拼对后自动进下一词（短延迟），拼错则展示差异、再回车继续。
4. **听力 TTS**：只删 VOA/真题里的 TTS（人在 VOA 页遇到双声）；逐句听写保留 TTS（唯一音源）。
5. **已听过**：播放真正开始才标记（客户端 onPlay → server action + revalidate）；
   已听条目沉底、未听置顶（VOA / 真题 / 听写三处一致）。
6. **真题卡片**：完成度 = 已作答客观题 / 客观题总数；100% 时显示原始得分（如 48/55），不换算 710。
7. **写作生成**：C 方案 —— 有 LLM key 则按题型自动选模板、生成题目+范文；无 key 回退库内真题范文。
   模板「结构固定、措辞可灵活」；范文后附挖空骨架，每空标注"这一句在回应题目的哪个部分"。
8. **错题自动汇入**：提交某板块后由服务端自动把错题写入错题本（去重，source=真题）。
9. **导出**：全词库导出，方向可选（英→中 / 中→英），格式 Excel + Word，带答案/不带答案；
   范围 = 当前筛选结果。
10. **考试/报名时间**：考试日期；报名开始日 + 截止日（三态显示：未开始 / 进行中 / 已结束隐藏）。

## 约束
- 数据放在本地 SQLite（prisma/cet6/dev.db），改动前自动备份。
- 每个阶段：typecheck → build → 重启 launchd 服务 → 页面与行为验证。
- 不引入需要联网运行时的依赖；导出若必须加包，先验证 registry 可达，否则手写 OOXML/SpreadsheetML。

## 开放问题（按默认处理，若不同意随时说）
- 拼错时长按回车的行为：先展示差异，再回车继续。
- 得分取值：按板块取最近一次尝试的 correct/total 汇总。
- 导出 Word 版式：表格 + 文末答案页（带答案时）。
